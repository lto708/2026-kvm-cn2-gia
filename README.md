## 优惠码怎么用：购买流程简述

虽然常规码大多失效，但流程还是要走一遍，万一遇到活动码能用上呢。

1. 在官网选择套餐和机房，点击 Order 进入结算页。
2. 在 Billing Cycle 选择计费周期（月付 / 季付 / 半年付 / 年付，年付通常比月付划算）。
3. 在配置选项里勾选是否需要额外服务（如自动备份、DDoS 防护等，部分收费）。
4. 在 Promotional Code 框输入优惠码，点击 Validate 验证。如果码有效，价格会立即显示折扣后金额；如果提示无效，就跳过这一步。
5. 确认配置和价格后，填写账户信息并完成支付。搬瓦工支持支付宝、银联、PayPal、信用卡等多种方式。

优惠码是循环折扣，续费时同样享受，所以即使折扣只有 5%-6%，长期算下来也能省一笔。这也是为什么老用户对 `BWHCGLUKKB` 这个码念念不忘——可惜目前它已经失效了。

## 几个常见疑问

**Q：搬瓦工还会恢复常规优惠码吗？**
官方没有明确表态。从 2025 年双十一取消常规码之后，期间只短暂放出过 `NODESEEK2026` 这类活动码。社区普遍猜测搬瓦工在调整促销策略，可能转向限时活动而非长期常规码。建议购买前先试码，无效就直接按原价下单，不要长期等待。

**Q：CN2 GIA-E 和香港 CN2 GIA 有什么区别？**
两者都走 CN2 GIA 线路，但机房位置不同。CN2 GIA-E 主机房在洛杉矶 DC6/DC9，延迟相对高（国内通常 150-180ms），但价格便宜，支持多机房切换。香港 CN2 GIA 机房在香港本地，延迟最低（国内通常 30-50ms），但价格贵得多，月付 $89.99 起，且不支持迁移到其他机房。简单说，预算优先选 GIA-E，延迟优先选香港。

**Q：限量版套餐和常规套餐有什么区别？**
限量版套餐是搬瓦工不定期推出的特价方案，配置通常和某款常规套餐接近，但价格低很多。比如 THE PLAN 限量版（2 核 2GB，年付 $99）和 CN2 GIA-E 40G 常规套餐（3 核 2GB，年付 $299.99）配置相近，价格差了三倍。代价是限量版库存不稳定，经常售罄，需要蹲守补货通知。

**Q：买了之后能换机房吗？**
CN2 GIA-E 套餐和 KVM 常规套餐支持在可选机房之间免费迁移，操作在 KiwiVM 控制面板里完成，数据不丢失。香港和日本 CN2 GIA 套餐通常只能在同区域机房内迁移，部分高端套餐不支持迁移，购买前要确认。

**Q：续费价格和首购一样吗？**
搬瓦工续费价格和首购价格一致，没有首购低价续费涨价的套路。如果购买时用了循环优惠码，续费时同样享受折扣。这也是为什么优惠码虽然折扣不大但仍有价值——长期续费能持续省钱。
